# Terminologia obrigatória — Projeto Exalted

Este documento orienta revisões de código, mensagens de progresso, relatórios técnicos, descrições de commits e textos da interface.

## Encantos Lunares

- Usar **Encanto** (singular) e **Encantos** (plural) para traduzir *Charm/Charms*.
- Usar **Encantos Lunares**, **Encantos Solares** e **Encantos de Sangue de Dragão** conforme o Tipo de Exaltado.
- **Não usar "amuleto" ou "amuletos"** como sinônimo de Encanto/Charm, inclusive em mensagens de inspeção ou auditoria.
- Mensagem correta: **"Inspecionando a seleção de Encantos Lunares"**.
- Diferenciar itens/equipamentos de Encantos: um amuleto que seja um objeto de jogo não é automaticamente um Encanto.
- Outras traduções adotadas: *Withering* = Fulminante; *Decisive* = Decisivo; *Clash* = Colisão; *Crash* = Atordoamento de iniciativa.

## Revisão

Antes de publicar mensagens de progresso, documentação ou textos da interface, verificar a terminologia acima. Este arquivo não altera regras de negócio nem inicia compilação.

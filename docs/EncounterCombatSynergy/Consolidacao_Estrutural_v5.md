# Consolidação estrutural v5

Pipeline alvo:

1. Catálogo bruto
2. Normalização semântica
3. Domínio/legalidade
4. RequirementExpression
5. PowerVariant
6. EffectBranch
7. MechanicalEffect (duração própria)
8. ActivationProfile / Type
9. Configuration consistency
10. EncounterCombinationEvaluator
11. SynergyEvidence + deduplicação causal
12. BuildState / RealizableSynergy
13. Route evaluation
14. Opportunity cost / continuity / diversity

Invariantes:
- Encantos nativos de Exaltados diferentes nunca se misturam.
- Regra explícita vence heurística.
- Type é barreira de realizabilidade.
- Dois Simple não recebem combinação de mesma rodada pela regra geral.
- AND/OR/NOT não são achatados.
- duração do Charm não é duração automática de cada efeito.
- variantes/ramos exclusivos não são somados.
- efeitos de Mastery/Terrestrial/Aura/Metamorfose/etc. não vazam para variante inaplicável.
- configurações incompatíveis não são somadas como simultâneas.
- a mesma relação causal não é pontuada várias vezes em camadas diferentes.
- incerteza não é promovida a sinergia integral.
- o sistema avalia construção; não escolhe ações de combate.
